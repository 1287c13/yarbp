# Подсветка

Здесь живёт всё, что связано с подсветкой кода:

| Файл | Роль |
| --- | --- |
| `YarbpHighlighter.js` | подсветка самой разметки ЯРБП в редакторе |
| `IndentGuides.js` | направляющие отступов и номера строк |
| `XMLHighlighter.js` | подсветка XML в панели результата |

## Традиционная схема 1С

BSL-профиль повторяет дефолтную схему конфигуратора 1С:Предприятие 8.3
(«красно-сине-зелёная»):

| Элемент | Цвет | Класс |
| --- | --- | --- |
| Ключевые слова | `#FF0000` (чистый красный) | `code-bsl-kw` |
| Операторы | `#FF0000` | `code-bsl-oper` |
| Идентификаторы | `#0000FF` (чистый синий) | `code-bsl-id` |
| Строковые константы | `#000000` (чёрный) | `code-bsl-str` |
| Числовые и датовые константы | `#000000` | `code-bsl-num` |
| Комментарии | `#008000` (зелёный) | `code-bsl-com` |
| Препроцессор и аннотации | `#963200` (коричневый) | `code-bsl-pre` |
| Фон | `#FFFFFF` | — |

В блоке используется мягкая подложка `#F4F7FB` (тёмная тема — `#17212B`),
чтобы отделить фрагмент от документа; сама схема 1С предполагает белый фон.

Источник точных значений — Infostart, «Приятная глазу цветовая схема 1С 8.х»
(статья 122391), раздел **Default colorschemes**:
<https://infostart.ru/1c/articles/122391/>. Там же: ключевые слова `FF0000`,
константы `000000`, идентификаторы `0000FF`, операторы `FF0000`, комментарии
`008000`, препроцессор `963200`, фон `FFFFFF`. Это и есть та самая резкая
красно-сине-зелёная расцветка, которую вспоминают как «традиционную».

Дополнительно сверялся SyntaxHighlighter-тема для 1С
(`latestalexey/Brush-and-theme-of-1C-Enterprise-for-SyntaxHighlighter`,
`shTheme1C.css`): `.keyword { color: red }`, `.comments { color: #008200 }`,
`.plain { color: blue }`, `.string { color: black }` — те же роли.

Важно: в дефолтной схеме **синие — идентификаторы**, а строковые константы
чёрные. Если нужна другая схема (например, со синими строками), это отдельная
настройка профиля, а не «дефолт 1С».

Для тёмной темы редактора те же роли адаптированы под тёмный фон:
`#FF6B6B` (ключевые/операторы), `#7FB3FF` (идентификаторы), `#E6E6E6`
(строки/числа), `#5FBF5F` (комментарии), `#D19A66` (препроцессор).

## Как устроен CodeBlockHighlighter

Профиль — набор «липких» правил (`y`-regex), применяемых с текущей позиции.
Правила идут в порядке приоритета: комментарий, препроцессор/аннотация,
строка, число, оператор, идентификатор. Всё, что не совпало, экранируется и
копируется как есть — `textContent` результата всегда равен исходному коду.

Язык берётся из info-строки fence (` ```bsl ` / `` `js ``). Без языка
встроенная подсветка не запускается. Неизвестный язык получает generic-профиль.
