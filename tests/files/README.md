# Файлы и хранилище

Набор про сохранность пользовательских данных: обёртка над `localStorage`
и round-trip «экспорт → импорт». Проверки выполняются настоящими модулями
редактора в headless Chrome/Edge (как `tests/lexer` и `tests/security`),
Node не нужен.

## Запуск

```powershell
python tests/files/run_tests.py
```

## Что покрыто

| ID | Проверка |
| --- | --- |
| — | `storage.js`: запись/чтение, числа как строки, удаление, `fallback` при отсутствии ключа |
| D-15 | при запрете хранилища (`window.localStorage` бросает): чтение не падает, запись/удаление возвращают `false`, `FileManager` создаётся и показывает встроенные примеры |
| D-12 | неудачная запись возвращает `false` и показывает метку «не сохранено» в шапке файлового менеджера |
| D-16 | экспорт: версия 2, у файлов есть `id`, у встроенных — `slug`, сохраняется активный файл |
| D-16 | импорт: `id` пользовательских файлов не меняются, активный файл восстанавливается, встроенные примеры не задваиваются |
| D-16 | устойчивость: дубли `id` разводятся, мусорные записи пропускаются, битые поля заменяются значениями по умолчанию, старый формат (v1) читается, битый JSON не меняет данные |
| D-05 | строка статуса под редактором: на корректном тексте скрыта; на незакрытой кавычке показывает строку, позицию и причину; недопустимый фрагмент получает класс `ide-code-unparsed`; после исправления статус снова скрыт |
| D-08 | подтверждение импорта содержит числа («сейчас N, в файле M»), перед заменой пишется резервная копия `yarbp_backup_*` с прежними файлами, отказ ничего не меняет и копию не создаёт, старые копии подрезаются до трёх |

## Как устроено

- экспорт перехватывается на уровне `URL.createObjectURL` /
  `HTMLAnchorElement.prototype.click` — тот же приём, что в
  `tests/flexforms/smoke.html`, поэтому скачивать файл в тесте не нужно;
- запрет хранилища имитируется `Object.defineProperty(window, 'localStorage',
  { get() { throw ... } })` с последующим восстановлением дескриптора;
  если браузер не разрешает подмену, проверки помечаются `skip`, а не падают;
- все тестовые ключи удаляются в конце, чтобы не мусорить в `localStorage`
  того origin, где открыт набор.
