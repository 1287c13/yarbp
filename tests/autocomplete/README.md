# `tests/autocomplete`

Сценарный UI-тест автодополнения конвертера ТСД. Проверяется не словарь
подсказок сам по себе, а поведение редактора глазами пользователя:

- начало пустого файла показывает hint-чип, а не список; `Tab` делает отступ;
- конвертер без словаря подсказок (`мермейд`, `json`, `openapi`, …) меню не
  открывает вовсе — ни при вводе, ни по `Alt`; исключения: начало пустого файла
  (курсор в позиции 0) и уже распознанная директива (внутри `! …` список
  директив работает при любом флейворе). В пустых строках ниже начала файла
  меню не появляется;
- `Alt` и `Ctrl+Space` открывают меню, `Escape` закрывает;
- ввод префикса не сужает список, а ранжирует его: совпадение поднимается
  наверх, остальные варианты остаются;
- меню видимо целиком: список реально занимает высоту (проверка на
  «схлопнутый popup»), а не просто существует в DOM;
- доки разделены: контекст («Свойства формы») стоит шапкой над списком,
  описание варианта — под списком и меняется вместе со стрелками;
- каретка, поставленная мышью, пересобирает подсказки для новой позиции,
  меню переезжает; закрытое меню от клика не открывается;
- `Tab` принимает подсказку, стрелки выбирают, `Shift+Tab` выравнивает строку;
- `Ctrl+Z` отменяет принятую подстановку: вставка идёт нативной командой
  `execCommand('insertText')`, поэтому попадает в историю отмены и возвращает
  набранный префикс (а `setRangeText` историю сбрасывает — раньше `Ctrl+Z`
  после подстановки молчал);
- `Tab` — отступ по сетке в два пробела: на чётном столбце добавляется два
  пробела, на нечётном — один;
- после `Tab` меню подсказок не открывается: табуляция — это отступ, и
  пользователь, скорее всего, будет табулировать дальше (иначе следующий `Tab`
  принял бы подсказку вместо отступа). Гасится ровно один проход подсказок —
  тот, что вызван `input` от самой табуляции; следующий ввод подсказывает как
  обычно (`Tab` и `Shift+Tab` ведут себя одинаково);
- `! ` (директива без тела) остаётся директивой: после `Tab` текст `! как `,
  второго `!` нет — замена покрывает и восклицательный знак;
- полная разметка формы ТСД собирается только подсказками: шапка,
  `..подписки`, `:обработчики`, операции, поля, `..опции`, таблица и колонки.
  Произвольные значения (иды, ссылки, код) набираются вручную;
- итоговая разметка разбирается без ошибок и даёт ожидаемый IR
  (`YarbpFlexFormsConverter`).

Стенд использует настоящие `SuggestionProvider`/`SuggestionUI`, лексер и
парсер. Тяжёлый рендерер предпросмотра ТСД здесь не участвует — он покрыт
`tests/flexforms`.

Запуск (из корня репозитория):

```powershell
python yarbp/tests/autocomplete/run_tests.py
```
