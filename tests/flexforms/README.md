# Тесты флейвора «форма-ТСД»

```bash
python yarbp/tests/flexforms/run_tests.py               # пример + браузерный дым
python yarbp/tests/flexforms/run_tests.py --no-browser  # только пример
python yarbp/tests/flexforms/run_tests.py --help
```

Зависимости: Python 3.8+ (только стандартная библиотека) и Chrome/Edge для
браузерного дыма. Внешних JS-пакетов, `quickjs` и каталогов вне репозитория нет.

| файл | что это |
| --- | --- |
| `run_tests.py` | раннер: компактный пример «Форма ТСД» в `FileManager` и браузерный дым |
| `smoke.html` | страница дымового теста: настоящие модули редактора + настоящий пример из «Примеров» |
| `builtin-ir.json` | ожидаемый IR компактного примера; сверяется с IR, собранным из `FileManager` в браузере |
| `../../tools/flexforms_mock_server.py` | Python-мок сервера для кнопки «мок-сервер»: хук, отправка, health; только стандартная библиотека |

IR-эталон `builtin-ir.json` собран JS-конвертером редактора
(`FlexFormsConvertor._applyDefaults`). После осознанной правки умолчаний его
нужно пересобрать тем же конвертером, иначе браузерный дым покажет расхождение.

`smoke.html` поднимается локальным `http.server` на корень репозитория (ES-модули
не грузятся с `file://`), браузер запускается в headless-режиме с `--dump-dom`,
вердикт читается из `<title>` и `<pre id="result">`, а IR, собранный из примера, —
из `<pre id="ir">` (он сверяется с `builtin-ir.json` побайтово).

Браузерный дым каждый раз стартует в свежем временном профиле и ждёт появления
`#track` в iframe (до 8 с), а не фиксированную паузу: так тест не зависит от
кеша Chrome и скорости загрузки страницы-хоста `src/preview.html`.

Разметку дым не копирует: он берёт текст предопределённого примера «Форма ТСД»
прямо из `FileManager` (`builtin-9`), то есть проверяет то, что видит
пользователь. В примере адрес сервера задан в шапке (`.сервис`), а `.хук`/`.урл`
относительные; дым проверяет и IR, и строку сервера, и склейку адресов.

В браузере дополнительно проверяется поведение формы внутри iframe:

| проверка | что ловит |
| --- | --- |
| `readOnly` + `inputmode="none"` у поля количества и ввод по `keydown` | «с выключенной клавиатурой нельзя ввести»: поле обязано оставаться `readonly`, а ввод — идти через мост сканера |
| `appearance === 'none'` у `input[type=number]` и его `::-webkit-inner/outer-spin-button` | типовой спиннер, который всплывает по наведению |
| `#track` → `translateX(-100%)` + `#stepNow` = `2` после свайпа | листание жестом и анимацию перехода |
| `data-theme` + `tsd-theme` в `localStorage` после перерисовки | сброс выбранной темы |
| `activeElement` после отрисовки: в предпросмотре не автофокус, в контрольной странице — автофокус | форсированный `setFocus()` движка, выдёргивающий каретку из окна кода |
| перехваченное скачивание кнопок «JSON», «HTML», «мок-сервер» | имена `.json` / `.html` / `.py`, содержимое и «молчащая» кнопка при неполном IR |
| `перезагрузить` отсутствует в IR операций, `отображатьСтатистику === true` | возврат к прежнему умолчанию и сброс после отправки |
| после отправки действия с `.урл`: строк таблицы 0, табло пересчитано, `#stepNow` = 1, снимок `tsd-form-state` удалён | «частичный» сброс |
| `.tools-row`: `position: static`, прокручивается `.app` | служебные кнопки, прилипшие к низу |
| число `.card.grid-card` = число групп операции в IR | «одна подложка на экран» |
| `.tbl-head` и `.empty` у пустой таблицы; `.row-add` и правка ячейки | потерянная шапка/счётчик, кнопка «нарисуй строку в DOM», значение, живущее только в DOM |

Описание флейвора и осознанных отличий от легаси — в
`yarbp/src/js/classes/renderers/flexforms/README.md`.
