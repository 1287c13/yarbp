## Дизайн ЯРБП разметки
1. Верхнеуровневый объект - участник, внутри участника описываются точки и триггеры, в каждой точке/триггере массив ```..аннотации``` , 
в нем массив строк из которых состоит аннотация. По часовой стрелке начиная с правой
2. Раскладка регулируется вручную внутри каждого актора с помощью пустых блоков 
3. Точки по умолчанию обязательные, ток в них активный
4. Ассоциации проставляются автоматически между всеми точками (триггер это не точка) в одной вертикали

## Пример разметки

```
! как кпо

участник = Клиент .картинка https://foo-bar.tech/

  точка = Я голоден
    ..аннотации
      Выход
      - Решение заказать пиццу

  точка = Оформление заказа 
    ..связи -- ->
    ..аннотации
      Каналы
      - Сайт
      - Телефон
      Действия
      - Выбор состава пицц и количества
      - Оформление заказа
      Выход
      - Состав пицц
      - Их количество
      - Адрес доставки

  точка = Где мой заказ? .тип -(*
    ..связи -- Телефон..
    ..аннотации
      Выход
      - Обновление информации о заказе

  точка = Получение заказа 
    ..связи -> <-
    ..аннотации
      Действия
      - Оплата заказа
      - Принятие товаров

  точка = Употребление .тип -о
    ..аннотации
      Выход
      - Пицца съедена, голод отступил


участник = Администратор .картинка https://foo-bar.tech/
  
  пусто

  точка = Заказ в работу
    ..связи -- ->
    ..аннотации
      Выход
      - Содержание заказа передано в работу

  точка = Обработка входящего
    ..связи нет
    ..аннотации
      Выход
      - Успокоенный клиент


участник = Повар .картинка https://foo-bar.tech/
  
  пусто

  точка = Приготовление
    ..аннотации
      Вход
      - Параметры заказа
      Выход
      - Пицца согласно заказу

  точка = Отправка
    ..связи нет ->
    ..аннотации
      Выход
      - Заказ упакован и передан курьеру

участник = Курьер .картинка https://foo-bar.tech/
  
  пусто
  
  пусто

  точка = Получение заказа
    ..аннотации
      Вход
      - Адрес
      - Информационное содержание заказа
      - Материалное содержание заказа

  точка = Выдача
    ..связи нет
    ..аннотации
      Вход
      - Получена оплата
```
