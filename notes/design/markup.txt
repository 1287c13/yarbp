      поле#запросЗаказа:штрихкод = Штрихкод заказа / Отсканируйте бланк заказа / *

        поле = Плановое количество: .значение 50 .постфикс шт.
        поле = Выполнено:           .значение 32 .постфикс шт.

    группа:плитка = 👷 Трудовые операции
      табы#трудозатраты --/ по умолчанию отражен первый, навигация задется в управляющих элементах
        таб#список -- видимо будут сложности с определенем строк списков: по идее в разметке без данных должна быть одна строка и ее метаданные это эталон всех строк. А если метаданные строк разные то не поддерживается добавление. Наверно это лучше различить типом. Плюс наверно пустые не отображаются
          группа:наборСоответствий
            поле#типОперации .значение Раскрой
            поле#количество .значение 12 .постфикс шт.
            поле = Комментарий: .значение -
          группа:наборСоответствий
            поле = Пошив:        .значение 8 .постфикс шт.
            поле = Комментарий:  .значение срочный заказ
          кнопка = + Добавить операцию
            .навигация #трудозатраты.добавить --/ id родителя и его ребенка, которого надо отобразить: найти родитля->скрыть содержимое->отобразить ребенка
        таб#добавить
          группа:плитка --/ цвета заливки и направление рендера чередуются от родителя к ребенку если их тип = "группа" и если не заданы явно
            ..доп-функционал очистить
            надпись      = Операция
            группа
              поле       = Тип операции
                опция        = Раскрой --/ если для опции не указаны значение и тип, то значение = представлению а тип - примитивный по правилам приведения
                опция        = Контроль
                опция        = Сборка
                опция        = Упаковка
              поле:число = Количество / Укажите кол-во / *
            поле         = Комментарий / что-то еще?
          кнопка         = Добавить
            ..источник #добавить     --/ если указаны группы то анализируются совпадения id полей этих групп и поля мэтчатся, если указаны id полей то они мэтчатся явно
            ..приемник #трудозатраты --/ алгоритм для мэтчинга по родителям: взять приемник и источник, получить id всех их детей и смэтчить
          кнопка         = <- Назад к списку
            .навигация #трудозатраты.список
            ..проверить #трудозатраты.добавить.количество --/ какие реквизиты нужно проверить (ищет среди явных и автосгенерированных id)
            .неуспех Очистите введенные данные или перенесите затраты в отчет / Ок
            .типПроверки пусто
