## 1. Введение

ЯРБП — это язык разметки, предназначенный для быстрого прототипирования пользовательских интерфейсов, бизнес‑процессов и структур данных.  
Язык ориентирован на русскоязычного аналитика и проектировщика, поэтому синтаксис максимально приближён к естественному русскому языку, не требует частого переключения раскладки и минимизирует количество специальных символов.

### 1.1. Философия

* **Простота чтения и написания** – основная цель.
* **Единый язык для разных представлений** – одна разметка может быть сконвертирована в JSON, XML, BPMN, HTML, Protobuf и другие форматы.
* **Семантика на стороне конвертера** – язык определяет только структуру, а смысл придаёт целевой конвертер.
* **Русскоязычность** – ключевые понятия и идентификаторы предпочтительно использовать на русском языке, а синтаксис адаптирован под русскую раскладку клавиатуры.

### 1.2. Концепция

Исходный файл имеет расширение **.yarbp** (или **.yar**).  
Разметка состоит из иерархии **тегов**, каждый тег описывает один элемент (объект, массив, атрибут, директиву).  
Вложенность задаётся **отступами** (два пробела на каждый уровень).  
Префиксы определяют тип элемента, а атрибуты уточняют его свойства.

## 2. Базовый синтаксис

### 2.1. Отступы и структура

Каждая строка может иметь отступ из чётного количества пробелов (2, 4, 6…).  
Уровень вложенности определяется количеством пробелов.

Пример:
```yarbp
объект
  атрибут = значение
    вложенный_объект
      .свойство значение
```

Структурно каждая строка (кроме пустых) представляет собой тег. Первый тег в строке начинается после отступа. 
Тег может быть:

- объектом (префикс : или без префикса),
- массивом (префикс ..),
- атрибутом (префикс .),
- директивой (префикс !),
- комментарием (начинается с --).

### 2.2. Комментарии

| Тип                         | Синтаксис | Описание                                                                 |
|-----------------------------|-----------|--------------------------------------------------------------------------|
| Обычный                     | -- текст  | Пояснение, докстринг                                                     |
| Важный                      | --! текст | Предупреждение, требует внимания                                         |
| Закомментированный фрагмент | --/ текст | Закомментировано для последующего удаления либо не важно для отображения |
|                             | --? текст | todo: задача, открытый вопрос                                            |
Тип	Синтаксис	Описание
Обычный	-- текст	Пояснение, докстринг
Важный	--! текст	Предупреждение, требует внимания
Закомментированный код	--/ текст	Временно выключенный код
TODO	--? текст	Задача, открытый вопрос
