# `notes`

Материалы, которые не входят в рантайм редактора:

| Папка | Что внутри |
| --- | --- |
| `cases/` | входные кейсы для golden-тестов лексера и парсера (`tests/lexer`) |
| `design/` | исторические макеты, схемы, прототипы и скриншоты (`render_examples/`) |
| `examples/` | примеры, которые намеренно не показываются в «Примерах» редактора (OpenAPI) |

Рантайм приложения лежит в `src/`; тесты — в `tests/`; утилиты командной
строки — в `tools/`.
